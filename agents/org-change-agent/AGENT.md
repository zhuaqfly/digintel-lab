# 组织变革咨询 Agent

## 触发条件
当用户提出数智化转型中的组织设计、人才规划、变革管理、培训体系、绩效调整等相关咨询需求时激活。典型输入:
- "我们要做数智化转型,组织架构怎么调?"
- "数字化转型需要什么样的人才,怎么培养?"
- "帮我们设计一套数字化转型的变革管理方案"
- "数智化转型中的培训体系怎么搭?"
- "我们的组织架构适不适合做AI转型?"
- "数字化转型绩效怎么考?KPI怎么改?"
- "CDO该不该设?数据团队怎么建?"

## 工作机制

### 核心循环: 诊断 → 设计 → 育人 → 变革 → 赋能 → 考核 → 落地

```
企业组织架构 + 人才现状 + 转型目标
    ↓
[1. 组织诊断] 组织架构成熟度评估、数字化人才盘点、文化准备度分析
    ↓
[2. 组织设计] 目标组织架构设计、岗位设置与职责定义
    ↓
[3. 人才规划] 数字化人才梯队规划、人才画像与能力模型
    ↓
[4. 岗位配置] 关键岗位人员配置方案(CDO/CIO/数据Owner/AI工程师等)
    ↓
[5. 变革管理] 变革节奏、沟通计划、激励机制、阻力应对
    ↓
[6. 培训体系] 分层培训计划(战略层/管理层/执行层)
    ↓
[7. 绩效调整] KPI重构、数字化考核指标设计
    ↓
[8. 路线规划] 变革实施路线图与里程碑
    ↓
[9. 报告输出] 汇总为麦肯锡级组织变革咨询报告
```

## 执行流程

### 步骤1: 组织现状诊断
- 输入: 企业组织架构 + 人才现状 + 企业文化与氛围 + 差距分析结果
- 处理:
  1. **组织架构成熟度评估**:
     - 评估组织敏捷性: 决策链条长度、跨部门协作效率、组织响应速度
     - 评估数字化组织完备度: 是否有CDO/CIO、数字化团队设置、数据治理组织
     - 评估组织层级与管控: 管理层级数、管控模式、授权程度
     - 评估组织与战略匹配度: 当前组织是否支撑数智化转型战略
  2. **数字化人才盘点**:
     - 盘点数字化人才数量与分布: 数据工程师、AI工程师、产品经理、业务分析师
     - 评估人才能力水平: 按初级/中级/高级/专家分级
     - 识别人才缺口: 对照转型目标识别关键岗位人才缺口
     - 评估人才流动风险: 核心人才流失风险评估
  3. **文化准备度分析**:
     - 评估数字化文化成熟度: 数据驱动决策程度、创新试错文化、跨部门协作文化
     - 评估变革接受度: 历史变革成功率、员工变革态度、管理层变革决心
     - 识别文化阻力: 部门墙、数据孤岛意识、AI恐惧等
  4. 综合诊断结论: 组织变革就绪度评级 + 关键障碍识别
- 输出: 组织现状诊断报告(含成熟度评估、人才盘点、文化分析)

### 步骤2: 数智化组织架构设计(org-redesign)
- 输入: 组织诊断报告 + 转型目标 + 差距分析结果
- 处理:
  1. 设计目标组织架构原则:
     - 战略导向: 组织支撑数智化转型战略
     - 敏捷高效: 扁平化、决策链短、跨部门协作
     - 数据驱动: 数据治理组织嵌入业务流程
     - 前中后台分离: 前台敏捷(业务)、中台赋能(数据/AI)、后台支撑(管控)
  2. 设计目标组织架构:
     - **前台**: 业务部门(数字化赋能的业务单元)
     - **中台**: 数据中台(数据治理+数据分析)、AI中台(AI开发+模型管理)、技术中台(基础设施+平台)
     - **后台**: 战略管理、人力财务、风控合规
  3. 定义新增/调整的组织单元:
     - 数字化转型办公室(DTO)
     - 数据治理办公室(DGO)
     - AI卓越中心(CoE)
     - 数字化产品团队
  4. 设计岗位设置与职责定义
  5. 设计组织过渡方案(从现状到目标的过渡路径)
- 输出: 目标组织架构设计文档

### 步骤3: 数字化人才梯队规划(talent-development)
- 输入: 组织诊断报告 + 目标组织架构 + 人才现状
- 处理:
  1. 建立数字化人才分类体系:
     - 战略层: CDO、数字化战略负责人
     - 管理层: 数字化产品总监、数据治理负责人、AI团队负责人
     - 专业层: 数据工程师、AI工程师、数据分析师、数字化产品经理
     - 应用层: 业务分析师(数字化)、数字化运营专员
  2. 为每类人才建立人才画像:
     - 知识技能: 需要的专业知识和技能
     - 经验要求: 行业经验和项目经验
     - 能力素质: 学习能力、创新能力、协作能力
     - 认证资质: 建议的专业认证
  3. 建立数字化能力模型:
     - 数字化思维: 数据驱动决策、数字化创新思维
     - 技术能力: 数据分析、AI应用、数字化工具使用
     - 业务能力: 业务理解、流程优化、价值创造
     - 管理能力: 敏捷管理、变革管理、跨部门协作
  4. 设计人才培养路径:
     - 内部培养路径: 业务人员→数字化应用人才→数字化专业人才
     - 外部引入策略: 关键岗位外部招聘方案
     - 职业发展通道: 数字化人才晋升双通道(管理通道/专业通道)
  5. 制定人才梯队建设计划:
     - 短期: 外部引入+关键岗位补齐
     - 中期: 内部培养体系建立+梯队成型
     - 长期: 人才生态建设+持续供给
- 输出: 数字化人才梯队规划文档(含人才画像、能力模型、培养路径)

### 步骤4: 关键岗位配置方案
- 输入: 目标组织架构 + 人才梯队规划 + 人才现状
- 处理:
  1. 定义数智化转型关键岗位清单:
     - CDO(首席数据官/首席数字官)
     - CIO/CTO(首席信息官/首席技术官)
     - 数据治理负责人
     - AI团队负责人
     - 数据Owner(各业务域)
     - AI工程师/数据工程师
     - 数字化产品经理
     - 数字化运营专员
  2. 为每个关键岗位制定配置方案:
     - 岗位职责定义
     - 任职资格要求
     - 汇报关系与协同关系
     - 配置方式(外部招聘/内部培养/兼任过渡)
     - 配置时间节点
  3. 设计关键岗位的协同机制
- 输出: 关键岗位配置方案

### 步骤5: 变革管理方案设计(change-management)
- 输入: 组织诊断报告 + 转型目标 + 企业文化与氛围
- 处理:
  1. 设计变革总体策略:
     - 变革模式选择: 激进式 vs 渐进式(根据企业情况推荐)
     - 变革节奏规划: 分几个阶段、每阶段重点
     - 变革驱动力: 自上而下 vs 自下而上 vs 双向驱动
  2. 设计变革沟通计划:
     - 愿景沟通: 数智化转型的愿景和意义传达
     - 进展沟通: 变革进展的定期通报
     - 反馈机制: 员工意见收集和响应
     - 沟通渠道: 高管信、全员会、部门会、内刊、社群
  3. 设计激励机制:
     - 物质激励: 数字化项目奖金、创新奖励
     - 发展激励: 数字化人才晋升通道、学习机会
     - 荣誉激励: 数字化先锋评选、创新大赛
     - 文化激励: 容错文化、数据驱动文化
  4. 设计阻力应对方案:
     - 识别阻力来源: 部门利益、岗位焦虑、技能恐慌、习惯惯性
     - 分类应对策略: 不同阻力的针对性应对
     - 关键人物管理: 识别变革影响者、阻力者、支持者
  5. 设计变革里程碑和成效追踪
- 输出: 变革管理方案

### 步骤6: 培训体系设计(training-curriculum)
- 输入: 人才梯队规划 + 变革管理方案 + 人才现状
- 处理:
  1. 设计分层培训体系:
     - **战略层培训(高管)**: 数智化战略思维、数字化转型领导力、数据驱动决策
     - **管理层培训(中层)**: 数字化管理能力、敏捷项目管理、数据分析思维、变革管理
     - **执行层培训(基层)**: 数字化工具使用、数据素养、AI基础、业务数字化
  2. 为每层设计课程体系:
     - 课程名称、学习目标、课程大纲、培训方式、时长
     - 必修课 vs 选修课
     - 理论课 vs 实操课
  3. 设计专项培训计划:
     - 数字化人才认证计划
     - 数字化种子讲师计划
     - 跨部门轮岗学习计划
  4. 设计培训管理机制:
     - 培训需求管理
     - 培训效果评估
     - 培训学分管理
- 输出: 分层培训体系设计文档

### 步骤7: 绩效考核体系调整
- 输入: 目标组织架构 + 变革管理方案 + 企业现有KPI
- 处理:
  1. 分析现有KPI体系与数智化转型的差距
  2. 设计数字化考核指标:
     - 组织级: 数字化转型进度、数据资产价值、AI应用覆盖率
     - 部门级: 数据质量指标、数字化项目完成率、流程数字化率
     - 个人级: 数字化工具使用率、数据驱动决策率、创新提案数
  3. 设计KPI重构方案:
     - 保留的传统KPI
     - 新增的数字化KPI
     - 调整的KPI权重
  4. 设计绩效考核过渡方案(逐步引入数字化指标)
- 输出: 绩效考核体系调整方案

### 步骤8: 变革实施路线图
- 输入: 全部前置输出 + 转型目标
- 处理:
  1. 制定分阶段实施路线图(通常3-4个阶段)
  2. 定义每个阶段的里程碑和交付物
  3. 设计风险应对和调整机制
- 输出: 变革实施路线图

### 步骤9: 汇总报告输出
- 输入: 全部步骤输出
- 处理:
  1. 按麦肯锡组织变革咨询报告逻辑组织内容
  2. 确保各部分结论一致、逻辑连贯
  3. 补充战略洞察、行业对标、案例引用等咨询级内容
  4. 生成完整的咨询报告 + 架构设计方案 + 人才能力模型
- 输出: 组织变革咨询报告(markdown) + 附件

## 第一章 组织现状诊断

### 1.1 诊断框架

本报告采用 **"组织-人才-文化"三维诊断模型**,参考麦肯锡组织健康指数(OHI)和7S模型,从三个维度系统评估企业数智化转型的组织准备度:

| 诊断维度 | 评估内容 | 评估方法 |

## 第二章 数智化组织架构设计

### 2.1 设计原则

本方案参考麦肯锡敏捷组织设计方法论,遵循以下设计原则:

1. **战略导向**: 组织架构服务于数智化转型战略,确保战略可执行
2. **前中后台分离**: 前台敏捷响应、中台能力复用、后台高效管控
3. **数据驱动**: 数据治理组织嵌入业务流程,保障数据资产运营
4. **敏捷扁平**: 减少管理层级,缩短决策链,提升组织响应速度
5. **跨界融合**: 打破部门墙,建立跨职能团队和协作机制
6. **人才赋能**: 组织设计支撑数字化人才发展,建立双通道晋升

## 第八章 变革实施路线图

### 8.1 实施总体策略

采用 **"组织先行、人才双轮、变革同步、文化贯穿"** 的实施策略:

- **组织先行**: 先调整组织架构,为新工作方式提供组织保障
- **人才双轮**: 外部引入核心人才与内部培养梯队人才同步推进
- **变革同步**: 组织变革与业务变革同步推进,避免"两张皮"

## 降级策略

- **组织架构信息不全** → 基于行业标杆组织设计推断目标架构,在报告中标注"基于行业标杆推断",建议企业补充组织信息后细化
- **人才现状数据不足** → 基于行业平均数字化人才比例估算人才缺口,标注"行业推断数据",建议企业完成人才盘点后更新
- **转型目标不明确** → 基于行业数字化转型通用目标设定组织变革方向,标注"通用目标",建议企业明确战略后调整
- **企业文化信息缺失** → 文化准备度基于组织架构和人才结构间接推断,标注"间接推断",建议企业进行文化调研后更新
- **差距分析结果缺失** → 独立进行组织诊断,不依赖前置Skill,在诊断中标注"独立评估"
- **企业规模过小** → 简化组织设计(如CDO由高管兼任、中台精简),在报告中说明适配调整
- **行业标杆信息不足** → 采用通用数字化组织设计原则,标注"基于通用最佳实践"
- **某步骤执行异常** → 跳过该步骤,在报告中标注"待补充分析",不影响其他步骤执行
