# 场景优先级排序方法论

不是所有场景都应该立即投入。场景优先级排序的核心是将有限的资源（资金、人才、时间）分配到价值最大、可行性最高的场景上，实现"好钢用在刀刃上"。本方法论参考RICE评分模型、ICE快速评估法和GE矩阵，设计"价值×难度"双维度评估框架，输出可决策的2×2优先级矩阵和TOP3推荐。

## 一、价值评估四维度

每个场景的综合价值得分（满分100分）由四个维度加权计算：

| 评估维度 | 权重 | 评分标准（1-5分，×权重系数） | 数据来源 |
|---------|------|---------------------------|---------|
| **业务价值** | 35% | 5=年价值>1000万/核心战略级；4=500-1000万/重要业务影响；3=100-500万/显著改善；2=50-100万/局部改善；1=<50万/锦上添花 | 业务部门估算+财务验证 |
| **紧迫性** | 25% | 5=业务已受损失/合规红线/Q1必须启动；4=本年度业务计划明确要求；3=1年内有需求；2=未来1-2年考虑；1=远期畅想 | 高管访谈+业务计划 |
| **数据就绪度** | 20% | 5=数据完整/质量高/实时可获取；4=核心数据存在需轻度清洗；3=主要数据存在需整合治理；2=部分数据缺失需补采；1=几乎无数据基础 | IT/数据团队评估 |
| **组织准备度** | 20% | 5=业务Owner主动推动/团队有数字化经验/预算已落实；4=业务方认可/有一定基础；3=业务方中立/需引导；2=业务方被动/有顾虑；1=业务方抵触/无意愿 | 访谈+问卷+变革评估 |

**价值总分** = 业务价值×35% + 紧迫性×25% + 数据就绪度×20% + 组织准备度×20%
得分归一化到0-100分，≥75分为高价值，50-74分为中价值，<50分为低价值。

## 二、难度评估四维度

每个场景的综合难度得分（满分100分）由四个维度加权计算：

| 评估维度 | 权重 | 评分标准（1-5分，×权重系数） | 数据来源 |
|---------|------|---------------------------|---------|
| **技术复杂度** | 30% | 1=成熟产品/RPA/报表；2=标准BI/规则引擎；3=常规ML预测模型；4=深度学习/复杂NLP/CV；5=前沿AI/大模型定制/自研算法 | 技术团队评估 |
| **数据依赖** | 25% | 1=单一系统/现成数据；2=2-3个系统/数据可获取；3=跨部门数据/需打通；4=外部数据/非结构化数据/需大量治理；5=数据缺失严重/需新建采集体系 | 数据团队评估 |
| **投入规模** | 25% | 1=<50万/2个月内；2=50-200万/2-4个月；3=200-500万/4-6个月；4=500-1000万/6-12个月；5=>1000万/12个月以上 | 项目经理+财务估算 |
| **变革阻力** | 20% | 1=仅涉及个人/工具升级；2=涉及小组/流程微调；3=跨部门/流程优化；4=涉及组织调整/岗位变化；5=涉及业务模式变革/利益重大调整 | 变革管理评估 |

**难度总分** = 技术复杂度×30% + 数据依赖×25% + 投入规模×25% + 变革阻力×20%
得分归一化到0-100分，<40分为低难度，40-69分为中难度，≥70分为高难度。

## 三、2×2优先级矩阵

以**价值**为纵轴、**难度**为横轴，将所有场景映射到四个象限：

```
        高价值
          ↑
          │
  速赢区  │  战略攻坚区
 (Quick   │ (Strategic
  Win)    │  Bet)
 ─────────┼────────→ 难度
  补充区  │  暂缓区
 (Fill-in │ (Later)
  )       │
          │
        低价值
       低难度     高难度
```

### 3.1 速赢区（高价值+低难度）——立即做
- **特征**：价值≥75分且难度<40分
- **策略**：Phase 1优先启动，2-3个月内见成效，快速建立信心
- **典型数量**：3-5个
- **案例**：报表自动化、标准RPA场景、数据看板搭建

### 3.2 战略攻坚区（高价值+高难度）——重点投入
- **特征**：价值≥75分且难度≥40分
- **策略**：Phase 1做POC验证，Phase 2规模化投入，需高管挂帅、专项保障
- **典型数量**：3-5个
- **案例**：智能排产、大模型知识助手、全渠道客户中台

### 3.3 补充区（低价值+低难度）——择机做
- **特征**：价值<75分且难度<40分
- **策略**：利用平台能力自助实现，或作为大场景的副产品顺带实现，不单独立项
- **典型数量**：3-5个
- **案例**：部门级小工具、简单数据查询

### 3.4 暂缓区（低价值+高难度）——暂不做
- **特征**：价值<75分且难度≥70分
- **策略**：放入场景池持续观察，等待条件成熟（技术进步/成本下降/数据积累/业务变化）
- **典型数量**：2-4个
- **案例**：完全自动驾驶、通用AI客服（在早期阶段）

## 四、TOP3推荐

从"速赢区"选取1-2个建立信心，从"战略攻坚区"选取1-2个锚定战略价值，形成POC阶段的TOP3推荐组合。

### TOP3选择原则
1. **速赢打底**：至少1个速赢场景，确保2-3个月内有可展示成果
2. **战略锚定**：1-2个战略级场景，对齐高管最关注的战略诉求
3. **能力互补**：覆盖不同技术类型（数据分析+AI+自动化），验证技术底座能力
4. **业务多元**：尽量覆盖不同业务域，避免单部门受益引发的公平性问题
5. **数据复用**：优先选择数据基础可复用的场景，降低POC数据准备成本

### TOP3推荐报告内容
- 每个推荐场景的详细场景卡
- 推荐理由（价值/难度/战略匹配度）
- POC成功后的推广路径
- 预期投入与资源需求

## 使用流程
1. 基于场景全景清单，组织跨部门评估会（业务+IT+数据+财务）
2. 每个场景独立打分，先打价值分再打难度分，避免光环效应
3. 汇总评分，绘制2×2矩阵，确定象限归属
4. 讨论有争议的场景（位于象限边界的），达成共识
5. 选出TOP3 POC场景，形成推荐报告
6. 提交转型委员会审批，作为POC立项依据
