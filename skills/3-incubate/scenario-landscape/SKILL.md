# 场景全景梳理方法论

场景是数智化转型的"战斗单元"——所有战略意图、架构设计、技术投入最终都要通过具体场景落地实现价值。本方法论参考BCG"数字化场景地图"、麦肯锡"AI Use Case Factory"和华为"场景五看"方法，提供系统化的场景识别框架，确保不遗漏高价值机会，同时避免"为场景而场景"的形式主义。

## 一、场景识别五维度法

从五个价值维度出发，结合业务流程遍历和痛点分析，系统识别数智化/AI应用场景：

### 1.1 效率提升维度
通过自动化、智能化手段减少人工操作、缩短处理时间。典型场景：
- 流程自动化：RPA替代重复性手工操作（对账/报表/录入/审批）
- 智能调度：资源/排产/路由的智能优化
- 自助服务：员工/客户自助完成常规操作，减少人工介入
- **价值度量**：人力节约FTE、处理时间缩短%、人工操作步骤减少%

### 1.2 成本降低维度
通过精准控制、减少浪费、优化配置降低运营成本。典型场景：
- 智能预测：需求预测/库存优化降低库存成本和缺货损失
- 质量优化：AI质检/预测性维护降低不良品率和停机损失
- 能耗优化：智能能源管理降低水电气消耗
- 采购优化：智能比价/供应商风险管控降低采购成本
- **价值度量**：成本节约金额、不良率降低pp、停机时间减少%、库存周转天数下降

### 1.3 收入增长维度
通过精准营销、智能推荐、产品创新驱动收入增长。典型场景：
- 精准营销：客户画像+智能推荐+个性化触达提升转化率
- 定价优化：动态定价/收益管理最大化收入
- 产品创新：数据产品/智能功能催生新收入来源
- 渠道优化：全渠道智能协同提升渠道效率
- **价值度量**：收入增长金额、转化率提升pp、客单价提升%、新客户获取成本下降%

### 1.4 体验提升维度
通过智能化手段提升客户体验和员工体验。典型场景：
- 客户侧：智能客服（NLP/大模型）、智能搜索、个性化推荐、数字人服务
- 员工侧：智能助手、知识问答、移动办公、智能审批
- **价值度量**：NPS/CSAT评分、首问解决率、响应时间、员工满意度eNPS

### 1.5 风险管控维度
通过实时监控、智能预警、合规检查降低经营风险。典型场景：
- 风控反欺诈：交易欺诈检测、信用风险评估
- 合规监控：智能合规审查、异常交易预警
- 安全生产：安全行为识别、危险源预警、应急响应
- 供应链风险：供应商风险预警、断供预测
- **价值度量**：风险事件减少%、损失金额规避、合规检查覆盖率、预警准确率

## 二、TOP15-20场景清单

通过五维度遍历，通常可识别30-50个候选场景。经过初步筛选，形成15-20个高潜力场景的全景清单。

### 筛选标准（三门槛）
1. **价值门槛**：预估年价值≥100万元（或占业务单元成本/收入的≥1%）
2. **可行门槛**：数据可获取、技术可实现、业务方有意愿
3. **战略门槛**：与企业战略方向对齐，非"有趣但无关"的场景

### 业务域分类
按企业业务域对场景进行分类，典型分类：
- **研发域**：智能研发辅助、知识管理、仿真优化
- **供应链/采购域**：需求预测、智能补货、供应商风险
- **生产/运营域**：智能排产、预测性维护、AI质检、能耗优化
- **营销/销售域**：精准营销、客户分群、智能推荐、线索评分
- **服务域**：智能客服、服务工单智能分派、售后预测
- **职能域**：财务RPA、HR智能招聘、法务合同审查、IT智能运维
- **管理域**：经营决策驾驶舱、风险预警、合规监控

## 三、场景卡标准格式

每个场景使用标准化"场景卡"描述，确保信息完整、可评估、可排序：

| 字段 | 说明 | 填写规范 |
|------|------|---------|
| **场景编号** | 唯一标识 | 域缩写-序号（如MK-01） |
| **场景名称** | 简明扼要 | 动词+对象+手段（如"基于NLP的客户投诉智能分类"） |
| **业务域** | 所属业务领域 | 研发/供应链/生产/营销/销售/服务/职能/管理 |
| **业务痛点** | 当前问题描述 | 量化痛点（每年损失X万元/耗时Y天/不良率Z%） |
| **解决方案概要** | 数智化手段 | 技术方案简述（用什么技术/数据/算法解决什么问题） |
| **价值预估** | 量化年价值 | 金额（万元/年）+价值类型（效率/成本/收入/体验/风控） |
| **技术难度** | 1-5分 | 1=RPA/报表，3=预测模型，5=大模型/复杂AI |
| **数据就绪度** | 1-5分 | 1=无数据，3=部分可用需治理，5=高质量实时数据 |
| **业务紧迫性** | 1-5分 | 1=远期畅想，3=1年内需要，5=紧急痛点 |
| **变革阻力** | 1-5分 | 1=无人反对，3=需协调，5=重大利益调整 |
| **优先级初评** | P0/P1/P2 | P0=速赢，P1=重点，P2=储备（后续矩阵精排） |
| **责任部门** | 业务Owner | 具体部门+负责人 |

## 使用流程
1. 基于业务能力地图和访谈纪要，按五维度法遍历业务流程识别候选场景
2. 组织跨部门工作坊（业务+IT+数据），头脑风暴补充场景
3. 按三门槛筛选，形成15-20个场景的初筛清单
4. 填写标准化场景卡，确保每个场景信息完整
5. 按业务域分类，形成场景全景图
6. 交付场景全景清单作为优先级排序的输入
