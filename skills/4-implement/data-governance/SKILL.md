# 数据治理体系建设方法论

数据是数智化转型的核心生产要素，数据治理是确保数据"可用、可信、可流通、可变现"的基础保障。本方法论基于DAMA-DMBOK2框架，结合国内企业数据治理最佳实践（DCMM贯标经验），设计"建组织、定标准、提质量、保安全、上工具、推落地"的六步法数据治理体系。

## 一、DAMA八大领域

数据治理体系覆盖DAMA-DMBOK定义的八大知识领域：

| 领域 | 核心内容 | 关键交付物 |
|------|---------|-----------|
| **数据治理** | 战略、组织、制度、流程、考核 | 数据治理章程、治理委员会运作机制、考核办法 |
| **数据架构** | 企业数据模型、数据流、数据分布 | 企业数据模型、数据流向图、数据资产目录 |
| **数据建模与设计** | 概念/逻辑/物理模型、数据标准化 | 统一数据模型、命名规范、设计规范 |
| **数据存储与操作** | 数据库管理、数据生命周期 | 存储策略、归档策略、备份恢复方案 |
| **数据安全** | 分级分类、权限管理、脱敏加密、审计 | 数据分级分类标准、安全策略、审计机制 |
| **数据集成与互操作** | ETL/ELT、API、数据交换 | 集成规范、接口标准、数据共享机制 |
| **文档与内容管理** | 元数据、数据字典、文档管理 | 元数据标准、数据字典、知识库 |
| **参考数据与主数据管理** | 主数据、参考数据、编码标准 | 主数据标准、主数据管理流程、编码体系 |
| **数据仓库与BI** | 数仓建设、指标体系、报表分析 | 数仓模型、指标库、BI报表体系 |
| **元数据管理** | 技术/业务/操作元数据、血缘分析 | 元数据管理平台、数据血缘图 |
| **数据质量管理** | 质量规则、质量监控、质量改进 | 质量规则库、质量报告、质量改进流程 |

## 二、三级治理组织

建立"决策-管理-执行"三级数据治理组织：

### 2.1 数据治理委员会（决策层）
- **组成**：CDO任主任，各业务VP、CIO、CFO为成员
- **职责**：审批数据战略/标准/政策、裁决数据争议、协调跨部门问题、审批重大数据投资
- **运作机制**：季度例会+临时专题会

### 2.2 数据Owner/数据管家（管理层）
- **数据Owner**：业务域负责人（如营销VP是客户数据Owner），对本域数据质量负最终责任
  - 职责：审批本域数据标准、确认数据质量规则、推动数据问题整改、保障数据安全
- **数据管家（Data Steward）**：业务域指定的数据管理专员，是Owner的执行代理
  - 职责：制定本域数据标准和质量规则、日常数据质量监控、协调数据问题处理、维护元数据

### 2.3 数据团队（执行层）
- **数据治理团队**：数据治理经理、数据标准专家、数据质量工程师
- **数据平台团队**：数据架构师、数据工程师、平台运维
- **数据应用团队**：数据分析师、数据科学家、BI工程师
- **职责**：平台建设、工具开发、技术支撑、数据服务提供

## 三、数据标准框架

### 3.1 主数据标准
核心主数据域：客户、产品/物料、供应商、员工、组织、账户
每个主数据标准包含：
- **数据定义**：业务定义、口径说明、适用范围
- **编码规则**：编码结构、码段含义、编码分配流程
- **属性标准**：属性名称、数据类型、长度、必填/可选、取值范围/枚举值
- **来源系统**：权威数据源（Golden Source）认定
- **管理流程**：新增/变更/合并/归档流程

### 3.2 指标数据标准
建立统一指标库，实现"同名同义、异名甄别"：
- 指标分类：业务指标（收入/订单/客户数）、流程指标（审批时长/周转天数）、技术指标（系统可用率/数据时延）
- 指标定义要素：指标名称、业务含义、计算公式、统计维度、统计周期、数据来源、责任部门
- 指标分级：公司级核心指标（KPIs）、领域级指标、部门级指标

### 3.3 编码/参考数据标准
- 统一编码体系：组织编码、产品编码、客户分类编码、区域编码等
- 参考数据管理：国家/地区/币种/行业/状态码等标准参考数据
- 编码映射：处理存量系统间编码不一致问题的映射关系

## 四、质量六维度评估

从六个维度评估数据质量，建立质量规则库和监控机制：

| 质量维度 | 含义 | 典型规则示例 | 度量方法 |
|---------|------|-------------|---------|
| **完整性** | 数据是否缺失 | 必填字段非空率、记录完整率 | 空值率、缺失率 |
| **准确性** | 数据是否正确 | 数值范围校验、格式校验、逻辑校验 | 错误率、异常值占比 |
| **一致性** | 跨系统/跨表数据是否一致 | 跨系统数据比对、逻辑关联一致性 | 一致率、差异率 |
| **及时性** | 数据是否及时更新 | 数据更新频率、数据时延 | 延迟时长、更新及时率 |
| **唯一性** | 数据是否重复 | 主键唯一性、去重规则 | 重复率、冗余记录数 |
| **合规性** | 数据是否符合规则 | 格式规则、业务规则、合规要求 | 合规率、违规记录数 |

### 质量闭环管理（PDCA）
1. **Plan**：定义质量规则、设定质量目标、制定监控计划
2. **Do**：执行质量检核、生成质量报告
3. **Check**：分析质量问题根因、评估影响范围
4. **Act**：推动源头整改、优化规则、跟踪验证

## 五、分级分类安全

### 5.1 数据分级
建立四级数据分级标准：
| 级别 | 标识 | 定义 | 典型数据 |
|------|------|------|---------|
| 公开数据 | L1 | 可对外公开 | 产品介绍、公开财报 |
| 内部数据 | L2 | 企业内部使用 | 内部流程文档、组织架构 |
| 敏感数据 | L3 | 泄露造成损失 | 客户信息、合同信息、经营数据 |
| 核心数据 | L4 | 泄露造成重大损失 | 核心算法、商业秘密、财务核心数据 |

### 5.2 数据分类
按业务领域分类：客户数据、财务数据、人力数据、研发数据、运营数据等，每类数据对应不同的管理策略。

### 5.3 安全管控措施
- **存储安全**：L3/L4数据加密存储、密钥管理
- **传输安全**：TLS/SSL加密传输、VPN专线
- **访问控制**：最小权限原则、RBAC/ABAC权限模型、审批流程
- **使用安全**：数据脱敏（动态/静态）、数据水印、数据防泄漏（DLP）
- **审计追溯**：操作日志、访问审计、异常行为监控
- **销毁安全**：数据销毁流程、存储介质销毁规范

## 六、分阶段路线

| 阶段 | 周期 | 重点任务 | 交付物 |
|------|------|---------|--------|
| **基础建设期**（Phase 1） | 0-6个月 | 组织搭建、制度发布、核心主数据标准制定、数据资产盘点、质量基线评估 | 治理章程、组织任命书、主数据标准V1.0、资产目录、质量基线报告 |
| **专项治理期**（Phase 1-2） | 6-18个月 | 核心主数据治理落地、质量问题专项整改、数据平台建设、安全体系落地 | 主数据管理系统、质量监控平台、数据分级分类、安全策略落地 |
| **运营深化期**（Phase 2-3） | 18-36个月 | 数据资产化运营、数据服务化、指标体系完善、数据文化培育、DCMM贯标 | 数据资产目录、数据服务API市场、指标平台、DCMM认证 |

## 使用流程
1. 开展数据资产现状盘点和成熟度评估（可与数据资产审计skill配合）
2. 设计三级治理组织，发布治理章程和任命
3. 优先制定核心主数据标准和指标标准
4. 在数据平台上部署数据质量监控和安全管控
5. 从最高优先级业务场景出发，以用促治，避免"为治理而治理"
6. 建立月度质量报告和季度治理委员会例会机制，确保持续运营
