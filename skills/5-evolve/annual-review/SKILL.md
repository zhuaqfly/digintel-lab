# 年度复盘方法论

年度复盘是数智化转型的"年度体检"——系统评估一年来的进展与成效，总结成功经验和失败教训，校准方向，规划下一年度的工作。本方法论结合美军AAR、联想"复盘方法论"和华为"年度民主生活会"经验，设计"目标回顾→KPI达成→重点项目复盘→经验教训→问题反思→下年计划"的六步年度复盘框架，并引入红黄绿健康度评估，全面客观地评估转型状态。

## 一、年度复盘框架

### 1.1 第一步：目标回顾
重温年初制定的年度转型目标和计划：
- **年度OKR/KPI回顾**：年初设定的目标是什么？关键结果有哪些？
- **年度重点工作计划**：年初规划的重点项目/任务清单
- **年度预算计划**：年初批准的预算是多少？投向哪些领域？
- **里程碑计划**：年初设定的年度里程碑有哪些？
- **关键假设**：年初制定计划时基于哪些假设？这些假设是否成立？

**操作要点**：
- 以年初正式发布的年度计划文档为准，不以记忆为准
- 对比年初目标与年内调整后的目标（如有调整需说明原因和审批流程）
- 客观陈述，不做评价，让所有人对"当初计划是什么"达成共识

### 1.2 第二步：KPI达成评估
用量化数据评估年度目标达成情况：

#### KPI达成评估表
| KPI类别 | KPI名称 | 基线值 | 年度目标 | 实际值 | 达成率 | 评价 |
|---------|---------|--------|---------|--------|--------|------|
| 财务 | 年化价值实现 | - | 2000万 | 2400万 | 120% | ✓超额 |
| 财务 | ROI | - | ≥0.5 | 0.6 | 120% | ✓达标 |
| 业务 | 速赢场景上线 | - | 5个 | 5个 | 100% | ✓达标 |
| 业务 | 核心流程数字化率 | 15% | 30% | 25% | 83% | ⚠差距 |
| 数据 | 主数据治理覆盖率 | 10% | 60% | 40% | 67% | ✗未达标 |
| 技术 | 数据平台上线 | - | Q3上线 | Q4上线 | 延期1季度 | ⚠延期 |
| 组织 | 数字化人才到位率 | - | 80% | 60% | 75% | ⚠差距 |

**评价标准**：
- ✓ 优秀：达成率≥120%
- ✓ 达标：达成率90-119%
- ⚠ 差距：达成率70-89%
- ✗ 未达标：达成率<70%

#### 投入执行评估
| 投入类别 | 年度预算 | 实际支出 | 执行率 | 偏差原因 |
|---------|---------|---------|--------|---------|
| 人力成本 | | | | |
| 技术/平台 | | | | |
| 外部服务/咨询 | | | | |
| 培训/变革 | | | | |
| **合计** | | | | |

### 1.3 第三步：重点项目复盘
对年度重点项目逐一复盘（每个项目1页纸总结）：
- **项目概况**：目标/范围/周期/团队/投入
- **成果评估**：交付物完成情况、KPI达成情况、价值实现情况
- **亮点与经验**：做得好的做法、可复制经验
- **问题与教训**：遇到的问题、根因分析、教训
- **后续计划**：推广/迭代/收尾/调整

#### 项目分级评估
| 项目名称 | 项目类型 | 状态 | 效果评级 | 关键经验/教训 |
|---------|---------|------|---------|-------------|
| 智能客服POC | AI场景 | 已推广 | ★★★★☆ | 大模型效果好，但需加强知识库建设 |
| 数据平台V1 | 平台建设 | 已上线 | ★★★☆☆ | 延期1季度，主数据治理需提前启动 |
| 精准营销 | 数据应用 | POC中 | ★★★★☆ | 业务方配合度高，效果超预期 |
| RPA财务 | 自动化 | 已上线 | ★★★★★ | 速赢效果明显，建议推广到HR/采购 |
| 数据治理 | 治理项目 | 进行中 | ★★☆☆☆ | 推进困难，业务方重视度不够 |

**效果评级**：★★★★★标杆项目/★★★★成功/★★★基本达成/★★部分达成/★未达预期

### 1.4 第四步：经验教训总结
从全年实践中提炼可复用的经验和需要避免的教训：

#### 经验分类汇总
| 经验类别 | 成功经验（Keep Doing） | 教训反思（Stop/Improve） |
|---------|---------------------|----------------------|
| 战略与治理 | | |
| 业务场景 | | |
| 数据治理 | | |
| 技术平台 | | |
| 组织人才 | | |
| 变革管理 | | |
| 项目管理 | | |

**经验提炼标准**：
- 每条经验必须具体到"在什么情况下，什么做法，导致了什么结果"
- ❌ "要重视数据治理" → ✅ "数据治理必须在项目启动前2个月开始，否则后续数据质量问题会导致模型开发延期30%以上"
- 成功经验和失败教训同等重要，"失败是最好的老师"
- 经验数量控制在10-15条，聚焦最深刻的认知更新

### 1.5 第五步：问题与根因反思
深入分析年度差距和问题的根本原因：

#### 问题根源分析（5-Why+归类）
| 核心问题 | 直接原因 | 根本原因 | 责任层面 |
|---------|---------|---------|---------|
| 主数据治理滞后 | 业务方不配合 | 数据Owner考核未落地，业务方无动力 | 治理机制 |
| 技术人才招聘慢 | 市场竞争激烈 | 薪酬体系不灵活、雇主品牌弱 | HR机制 |
| 业务部门参与度低 | 认为是"IT的项目" | 数字化KPI未纳入业务部门考核 | 考核激励 |

**关键区分**：
- **执行问题**：计划合理但执行不到位（加强执行力）
- **计划问题**：计划本身不切实际（改进计划方法）
- **外部问题**：环境变化导致（增强敏捷性和应变能力）
- **能力问题**：能力不足（补能力、引人才）

### 1.6 第六步：下年度计划
基于复盘结论制定下一年度计划：

#### 下年度目标设定
- 基于三年路线图的年度分解
- 基于当年实际进展的调整
- 基于外部环境变化的更新
- 保持**挑战性与可达性平衡**（基于今年实际达成的120-150%设定下年目标）

#### 下年度重点工作
| 重点方向 | 关键举措 | 预期成果 | 责任部门 | 季度节奏 |
|---------|---------|---------|---------|---------|
| | | | | Q1/Q2/Q3/Q4 |

#### 资源需求
- 预算需求（分类型）
- 人才需求（新增编制+关键岗位）
- 组织调整需求

## 二、红黄绿健康度评估

从五个维度评估数智化转型的整体健康度，每个维度按红/黄/绿三色标识：

| 评估维度 | 评估要点 | 🟢绿色（健康） | 🟡黄色（预警） | 🔴红色（危险） | 当前状态 |
|---------|---------|--------------|--------------|--------------|---------|
| **战略对齐** | 高管共识度、战略清晰度、资源保障 | 高管层高度共识、战略清晰、资源到位 | 部分高管有疑虑、战略需细化、资源基本保障 | 高管层分歧大、战略模糊、资源不到位 | |
| **进度执行** | 里程碑达成率、项目按时率、预算执行率 | ≥90%项目按计划推进 | 70-90%项目按计划，关键项目有延期 | <70%项目按计划，大面积延期/超支 | |
| **价值实现** | KPI达成率、ROI、业务方满意度 | ≥90%KPI达成，ROI符合预期，业务方满意 | 70-90%KPI达成，部分价值未兑现 | <70%KPI达成，价值不显著，业务方质疑 | |
| **能力建设** | 数据能力、技术能力、人才能力 | 平台稳定运营、数据质量达标、人才到位率≥90% | 平台基本可用、数据质量需提升、人才到位率70-90% | 平台不稳定、数据质量差、人才严重不足 | |
| **风险管控** | 重大风险数量、风险应对有效性 | 无重大风险、风险可控 | 有1-2项重大风险但有应对方案 | 重大风险无应对、出现项目失败/安全事故 | |

### 综合健康度判定
- **全绿或1黄**：健康，按计划推进
- **2-3黄**：亚健康，需关注并针对黄色维度制定改善计划
- **1红或≥4黄**：不健康，需暂停部分项目，专项整改
- **≥2红**：危险，需重新评估转型战略和方案

## 三、改进计划

基于复盘结论和健康度评估，制定针对性的改进计划：

| 改进领域 | 问题描述 | 改进措施 | 责任人 | 完成时间 | 优先级 |
|---------|---------|---------|--------|---------|--------|
| | | | | | P0/P1/P2 |

**改进原则**：
- P0改进项（必须在下年Q1完成）：红色维度整改、重大风险应对
- P1改进项（H1完成）：黄色维度改善、机制流程优化
- P2改进项（年内持续推进）：能力建设、文化培育

## 使用流程
1. **复盘准备（12月中-下旬）**：PMO牵头收集全年数据、项目报告、KPI数据，提前发给参会人
2. **数据收集**：各部门提交年度工作总结和数据，PMO统一汇总校验
3. **复盘会议（1-2天）**：
   - Day 1上午：目标回顾+KPI达成（客观数据呈现）
   - Day 1下午：重点项目复盘（成功+失败案例）
   - Day 2上午：经验教训+问题根因（深入讨论，不回避问题）
   - Day 2下午：下年计划+改进措施（面向未来）
4. **复盘氛围**：CEO/CDO带头自我批评，营造"对事不对人"的安全氛围
5. **报告输出**：会后1周内输出复盘报告，经CDO审核后报CEO和董事会
6. **跟踪落地**：改进计划纳入下年Q1工作，季度跟踪进展
