# 数智化成熟度评估

## 触发条件
当需要对企业数字化转型/智能化转型的当前阶段进行系统评估时激活。典型场景:咨询项目启动阶段、年度数字化转型复盘、转型规划前的现状摸底。

## 前置条件
- 已获取企业基本信息和IT系统清单
- 如有企业内部调研问卷结果则更佳

## 评估模型: L1-L5 五阶成熟度

### 成熟度等级定义

| 等级 | 名称 | 核心特征 | 典型表现 |
|------|------|---------|---------|
| L1 | 系统支撑级 | 业务线上化,数据分散 | 各业务独立线上化,依靠人工汇总报表,无统一标准 |
| L2 | 数据整合级 | 数据集中,基础看板 | 搭建数据中台/数仓,多系统数据汇聚,指标未统一 |
| L3 | 指标穿透级 | 统一指标,多层下钻 | 集团统一指标体系,财务/项目/采购主题模型,数据成为管理语言 |
| L4 | 智能分析级 | 自动预警,智能分析 | 自动风险预警,智能分析能力,AI辅助决策 |
| L5 | 自主演化级 | AI自主决策,全流程闭环 | AI自主决策,全流程智能闭环,持续自学习优化 |

### 七大评估维度

1. **数据基础**: 数据采集覆盖率、数据质量、数据标准统一程度
2. **指标体系**: 指标统一程度、多层穿透能力、指标治理机制
3. **穿透监管**: 数据溯源能力、全链路可视、风险穿透覆盖
4. **经营分析**: 分析深度、实时性、预测能力
5. **智能应用**: AI场景覆盖、模型成熟度、业务闭环程度
6. **数据运营**: 数据资产化、数据服务能力、持续运营机制
7. **安全可信**: 数据安全、自主可控、合规治理

## 执行流程

### 步骤1: 信息收集与确认
- 输入: 企业基本信息、系统清单、数据现状、组织情况
- 处理: 
  1. 梳理企业行业属性和业务特点
  2. 确认已建系统覆盖的业务范围
  3. 识别数据流和系统集成关系
- 输出: 企业数字化现状摘要

### 步骤2: 维度逐项评分
- 输入: 步骤1的现状摘要
- 处理: 对七大维度逐一评分(1-5分),评分标准如下:
  - **数据基础**: 1分=纸质/Excel为主 → 3分=核心系统数据化 → 5分=全域多模态数据治理
  - **指标体系**: 1分=无统一指标 → 3分=部分统一 → 5分=集团级统一指标+自动下钻
  - **穿透监管**: 1分=事后人工核查 → 3分=定期报表 → 5分=实时全链路穿透
  - **经营分析**: 1分=手工统计 → 3分=BI看板 → 5分=AI预测+智能归因
  - **智能应用**: 1分=无AI应用 → 3分=试点AI场景 → 5分=全域AI自主决策
  - **数据运营**: 1分=无运营 → 3分=有数据服务 → 5分=数据资产化+持续运营
  - **安全可信**: 1分=基础安全 → 3分=有安全体系 → 5分=信创+全流程可审计
- 输出: 七维度评分表

### 步骤3: 综合定级
- 输入: 七维度评分表
- 处理: 
  1. 计算加权综合分(权重可按行业调整,默认等权)
  2. 综合分 1.0-1.8 → L1, 1.8-2.6 → L2, 2.6-3.4 → L3, 3.4-4.2 → L4, 4.2-5.0 → L5
  3. 取各维度最低分作为"短板维度"
- 输出: 成熟度等级 + 短板识别

### 步骤4: 差距分析与改进建议
- 输入: 当前等级 + 目标等级(默认目标为当前+1级)
- 处理:
  1. 逐维度分析当前等级与目标等级的差距
  2. 识别关键阻塞点
  3. 给出分阶段改进建议(短期3个月/中期6-12个月/长期1-2年)
- 输出: 差距分析表 + 改进路线图

### 步骤5: 报告生成
- 输入: 前四步全部输出
- 处理: 按输出模板组装完整评估报告
- 输出: 成熟度评估报告(markdown) + 雷达图数据(json)

## 降级策略
- 企业信息不完整 → 基于行业平均水平进行预评估,标注"待补充信息"
- 无法获取系统清单 → 从公开信息和行业推断,标注"推断数据"
- 仅了解部分维度 → 对已知维度评分,未知维度标注"待评估"

## 关联 Skill
- 上游: 无(诊断评估域入口Skill)
- 下游: 
  - `readiness-diagnosis` (AI就绪度诊断) — 承接成熟度结果,深入评估AI能力准备度
  - `gap-analysis` (差距分析) — 基于评估结果做详细差距分析
  - `top-level-design` (顶层设计) — 基于评估结果制定转型蓝图
